# Blog

Personal blog and travel photo wall.

This site is used to keep personal writing, life records, and travel memories in a lightweight static format.

## Contents

- `index.html` — homepage
- `now.html` — current status page
- `experience.html` — experience and records page
- `404.html` — not found page
- `deploy.sh` — deployment helper

## Deployment

The site is designed as a static website and can be deployed with Cloudflare Pages or any static hosting provider.

## Notes

Public content should focus on personal experience, AI-assisted life, travel, and practical reflections.
